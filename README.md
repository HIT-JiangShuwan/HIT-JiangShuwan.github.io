# Shuwan Jiang — Academic Homepage

Personal academic website of **Shuwan Jiang** (Shawn), Harbin Institute of Technology.

Live site: <https://hit-jiangshuwan.github.io/introduce.github.io/>

Built from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages.

## Edit the site

| What | Where |
| --- | --- |
| Name, email, sidebar | `_config.yml` |
| Homepage bio | `_pages/about.md` |
| Publications | `_publications/` |
| Projects | `_portfolio/` |
| CV | `_pages/cv.md` |
| Profile photo | `images/profile.png` |
| Top menu | `_data/navigation.yml` |

After pushing to `master`, GitHub Actions builds and deploys the site. In the repository, set **Settings → Pages → Source** to **GitHub Actions**.
